# Integration ASA Connection OpenAPI with NodeJS

This example demonstrates the integration to ASA Open API with NodeJS usage, without relying on any external libraries. 

## Configuration

Before starting code usage you need to change parameters/setting  in `config.js` file.  To obtain values please contact ASA team


## Running sample 

When `config.js` is properly configured you can run a sample, receive access token and use it to get data from the secure end points.
This token can be used to access any other ASA secure endpoint described in AsaOpenAPI documentation, which is out of scope of this example
